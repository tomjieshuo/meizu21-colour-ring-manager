# 灵动光环控制（MEIZU 21）

独立 Android 项目，仅控制 AW20072 RGB 灵动光环，不包含 Flyme 工具箱代码或资源。

## 当前实现（实验原型）
- 单色：色相滑杆选择颜色。
- 彩虹：每 120ms 改变一次色相并向驱动写入颜色。
- 亮度：1–63。
- 关闭：向 effect 节点写入 0。
- 通过 `su` 获取 Root，尝试写入 `/sys/class/leds/aw20072_led/`。

## 重要限制
**这是未经实体魅族 21 验证的实验原型，不是已确认可用的驱动提取版。** 当前假设 `all_light` 和 `effect` 节点存在，且接受相应写入格式；这些节点路径和命令格式尚未从 Flyme 驱动控制流程中证实。安装成功或 GitHub Actions 构建成功不代表灯环一定能工作。

彩虹模式由应用前台循环驱动，离开应用或进程被系统结束后不会保证继续运行。

## 构建
GitHub Actions 会在推送代码时自动构建 Debug APK。也可以使用 Android Studio 打开项目构建。
